# TradingHub (TH) - Command Center & Research Platform

A personal, high-performance trading command center, market research hub, and trade execution journal designed for active traders.

Live Repository: [https://github.com/Hiokz/trading](https://github.com/Hiokz/trading)

---

## 🚀 Features

- **Technical Analysis Hub**: Visual price action principles, momentum indicator cheatsheets, and one-click TradingView integration.
- **Fundamental & Macro Analysis**: Macro indicators, Federal Funds Rate monitors, yield curves, and economic catalyst checklists.
- **Quantitative Trading Lab**: Python & VectorBT quant stack references, mathematical performance formulas (Sharpe, Sortino, Kelly Criterion).
- **Backtesting Laboratory**: Interactive run recorder, strategy parameter logs, win rate & profit factor tracking with `localStorage` persistence.
- **Market News Wire**: Real-time financial feeds featuring Bloomberg Markets, Yahoo Finance, and Forex Factory economic calendar.
- **Market Data & Microstructure**: Live market session clocks (New York, London, Tokyo), order flow tools, and heatmaps.
- **Personal Trading Journal**: Fast execution logger with P&L calculations, strategy attribution, mistake reflection, and statistics.
- **Risk Management Calculator**: Real-time position sizing calculator based on equity risk percentage, stop loss distance, and asymmetric R:R.
- **Command Palette (`Ctrl + K`)**: Instant keyboard navigation across all tools and sections.
- **Data Portability**: Full JSON export and restore for all journal and backtest logs.

---

## 💻 Tech Stack

- **HTML5 & CSS3**: Glassmorphism aesthetic, deep zinc dark mode (`#09090b`), crimson red accents (`#ef4444`), responsive layout.
- **Vanilla JavaScript**: Pure client-side architecture with zero dependencies, offline-ready, `localStorage` persistence.
- **Icons & Typography**: FontAwesome 6, Inter, and General Sans.

---

## 🛠️ Usage

Simply open `index.html` in any modern web browser or serve via any static web server / GitHub Pages.
